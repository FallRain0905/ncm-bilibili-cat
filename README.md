# Music Cat（ncm-bilibili-cat）

> 原名"NCM 转换器"。本地 NCM 转换 + Bilibili 音频下载 + 网易云歌单导入与批量下载。

**项目主页 / 源码**：<https://github.com/FallRain0905/ncm-bilibili-cat>

**许可与使用条款**：本项目源码公开，仅供个人学习与非商业用途。**禁止倒卖、收费分发和任何商业用途**（详见 [LICENSE.md](LICENSE.md)）。本软件仅允许下载你本人登录自己的网易云账号后有权收听/下载的歌曲，以及你自己有权访问的 Bilibili 内容；不破解、不绕过任何平台会员或访问控制。首次启动时应用会展示完整的《用户协议与使用条款》，点击"同意并继续"后才能使用，同意记录只保存在本机。

本项目可将网易云下载的 `.ncm` 文件转换为 FLAC 或 MP3。原始文件默认不会被删除。

## 桌面应用

构建后的应用位于 `dist\MusicCat\MusicCat.exe`。双击启动后可以：

- 选择一个或多个 `.ncm` 文件，或选择文件夹
- 选择是否递归处理子目录
- 选择 FLAC 或 MP3
- 选择输出目录
- 选择转换成功后是否删除源文件
- 查看实时日志、进度、跳过和失败统计
- 在“音乐管理”页面查看歌曲、转换状态和输出路径
- 将 `.ncm` 文件或文件夹直接拖入“音乐管理”页面
- 在管理列表中筛选未转换、已转换、目标缺失或已下载歌曲并加入转换
- 在“下载”页面输入 Bilibili BV 号或视频链接，获取视频信息和分 P 列表后下载音频为 MP3、M4A 或 FLAC
- 在“歌单”页面输入网易云歌单链接或 ID，导入完整歌曲列表（歌名、歌手、专辑、状态），全选或筛选后多选，一键批量加入下载队列

“下载”页面用法：输入 BV 号（如 `BV1GJ411x7h7`）或视频链接（支持 `b23.tv` 短链接）→ 点击“获取信息”→ 在分 P 列表中选择要下载的分 P → 点击“加入下载”→ 选择音频格式、音质和下载目录 → 点击“开始下载”。下载在后台线程串行执行，可随时停止；目标文件已存在时自动跳过。下载页底部有“运行日志”（实时显示每个任务的第几次尝试、跳过、完成、重试和失败原因）与“任务详情”面板（选中任务后显示错误信息、输出路径和实际音质），下载中的任务显示“下载中”，失败任务在列表中标红。下载结果会写入本机历史记录，并在“音乐管理”页面以“已下载”状态显示（不经过 NCM 转换）。公开视频无需登录；会员、付费、私有或地区受限内容会直接显示平台返回的权限错误，应用不会尝试绕过任何访问限制。下载功能基于 yt-dlp，Bilibili 接口变更时需要更新 yt-dlp 版本。

“歌单”页面用法：先在“网易云登录”区点击“登录…”。登录对话框默认使用**扫码登录**：用网易云音乐 App 扫一扫并确认即可完成登录，应用自动获取并加密保存凭据（二维码过期可一键刷新）。无法扫码时可切换到"Cookie 粘贴"方式：推荐用浏览器插件 Cookie Control Center 或 Cookie-Editor——登录 music.163.com 后在插件里搜索 MUSIC_U 复制 Value 粘贴；也可以按 F12 → 应用/存储 → Cookie 手动查找。凭据使用 Windows DPAPI 加密只保存在本机，绝不写入设置文件或日志，可随时"退出登录"删除。然后输入歌单链接（如 `https://music.163.com/#/playlist?id=123456`）或纯数字 ID → 点击"导入歌单"→ 等待列表加载（大歌单自动分批获取）→ 按状态筛选（免费/VIP/限免/无版权等）→ 选择歌曲 → 点击"加入下载"→ 到"下载"页点击"开始下载"。下载按"下载目录/歌手 - 歌名.格式"保存；实际音质（标准/较高/极高/无损）会标注在日志和历史记录中，不会把请求音质误报为实际音质；试听片段会明确标注。未登录时 fee=8 的歌曲通常可直接下载，VIP 与无损需要账号有对应权限；无版权、下架或无权限的歌曲会显示具体原因。导入只读取公开歌单数据，不会自动下载；上次输入的歌单链接会自动记忆。

说明：网易云的二维码登录接口（weapi）对本应用的请求返回空响应，无法在应用内实现扫码，因此采用导入 MUSIC_U 的方式；这是唯一要求用户提供的凭据，且始终加密存储。

应用会自动保存输入目录、输出目录、FLAC/MP3 格式和递归选项，下次启动优先恢复。设置保存在 `%LOCALAPPDATA%\MusicCat\settings.json`（旧版 NCMConverter 目录会自动迁移），不会跟随应用 ZIP 分发给其他用户。修改后会自动保存，关闭应用时也会保存；删除源文件开关每次启动仍默认关闭。

首次启动或上次输入目录已经不存在时，应用只读查询网易云本地下载记录中的目录；读取失败或没有记录时，检查用户音乐目录、常见 `CloudMusic` 目录及本地固定磁盘下的 `CloudMusic`。不能识别时输入目录留空，可手动选择。自动识别不会开始转换，不读取 Cookie 或登录凭据，也不会修改网易云配置。网易云版本变更或自定义目录没有下载记录时，自动识别可能不可用。

拖放功能使用 `tkinterdnd2`。如果当前环境未安装该依赖，仍可使用文件/文件夹选择按钮。

界面基于 `ttkbootstrap` 主题，默认深色，可用转换页的“切换主题”按钮切换深色/浅色（偏好会自动记忆）。应用已适配高 DPI 显示。

应用目录必须整体保留，尤其是 `_internal` 文件夹（随包工具位于 `_internal\bin`）。

## 命令行脚本

```powershell
# 解码并保留 FLAC（默认）
.\转换.ps1

# 转码为 MP3
.\转换.ps1 -Format mp3

# 指定其他下载目录或输出目录
.\转换.ps1 -Format flac -SourceDir 'D:\CloudMusic\VipSongsDownload' -OutputDir 'E:\Music\FLAC'
```

也可以双击 `转换.bat` 默认转换为 FLAC，或在命令行运行 `转换.bat mp3` 转为 MP3。已有同名输出会跳过；MP3 转换会在编码成功后移除中间 FLAC。输出目录按源目录的子目录结构保存。命令行脚本同样依赖 `ncmdump` 与 FFmpeg 可执行文件（放置路径见上）。

## 从源码构建

本仓库不含第三方二进制（体积原因），构建前需要自行放置两个工具：

1. **ffmpeg / ffprobe**：下载 [FFmpeg essentials 构建](https://www.gyan.dev/ffmpeg/builds/)（Windows，版本 9.0.2 或兼容版本），解压后放到：
   `tools\ffmpeg-9.0.2-essentials_build\bin\ffmpeg.exe` 与 `...\bin\ffprobe.exe`
2. **ncmdump.exe**：从 [ncmdump releases](https://github.com/taurusxin/ncmdump/releases) 下载 1.5.1 版本，放到：
   `ncmdump\tools\ncmdump-1.5.1\ncmdump.exe`

然后安装 Python 3.12+ 与依赖，再构建：

```powershell
python -m pip install -r requirements.txt
.\build_app.ps1      # 仅构建应用（PyInstaller onedir）
.\build_installer.ps1  # 构建应用 + Inno Setup 安装包（需要 winget install JRSoftware.InnoSetup）
```

## 安装包

运行以下脚本会先构建应用，再用 Inno Setup 编译标准 Windows 安装程序：

```powershell
.\build_installer.ps1
```

产物为 `installer\MusicCat-1.2.0-setup.exe`（中文安装向导、可选桌面快捷方式、开始菜单、卸载器，含 `THIRD_PARTY_NOTICES.md` 第三方声明）。安装包默认按当前用户安装（无需管理员），也可在向导中选择为所有用户安装。
